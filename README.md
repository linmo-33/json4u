<h1 align="center">JSON For You</h1>

这是一个面向个人使用的精简版 JSON 工具，Fork 自原项目 [loggerhead/json4u](https://github.com/loggerhead/json4u)。当前版本仅保留核心的 JSON 查看与处理能力。

## 功能

- JSON 编辑、校验、格式化、压缩和自动格式化
- JSON 键排序、转义与反转义、嵌套 JSON 解析
- 文本、关系图和表格三种查看方式
- JSON 结构比较与普通文本比较，支持差异高亮和同步滚动
- 关系图和表格搜索，以及节点内容编辑
- jq 1.7 查询与转换
- JSONPath 查询
- URL 参数转 JSON、Python Dict 转 JSON
- JSON、TXT 和 CSV 文件导入，JSON 和 CSV 文件导出
- 日期、时间戳、颜色、图片、URL、Base64、URI、JWT 和 Unicode 悬停预览
- 根据浏览器语言加载中文或英文界面
